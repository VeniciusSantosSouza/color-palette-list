# 🎨 Color Palette List

### Explore cores. Crie experiências. Construa interfaces melhores.

Uma coleção curada de **100 paletas de cores** para UI/UX, Design Systems e produtos digitais, com códigos HEX, papéis semânticos e sugestões de aplicação.

## 📌 Sobre o projeto

O **Color Palette List** é uma ferramenta visual desenvolvida para facilitar a descoberta e a seleção de combinações cromáticas em projetos digitais.

A coleção reúne 100 paletas organizadas alfabeticamente, com informações que ajudam designers e desenvolvedores a compreender não apenas quais cores combinar, mas também como aplicá-las de forma consistente em interfaces.

O projeto busca tornar a escolha de cores mais prática, organizada e alinhada às necessidades de cada produto digital.

## ✨ Recursos

| Recurso | Descrição |
|---|---|
| 🎨 **Paletas de cores** | Coleção com 100 combinações cromáticas. |
| 🔎 **Busca dinâmica** | Pesquisa por nome, código HEX, categoria e outras informações disponíveis. |
| 🧩 **Filtros** | Refinamento das paletas por categoria e aplicação. |
| 📋 **Copiar código HEX** | Clique em uma amostra para copiar seu código de cor. |
| 💬 **Feedback visual** | Notificação para confirmar a cópia de uma cor. |
| 🏷️ **Papéis semânticos** | Identificação das funções das cores, como fundo, superfície e destaque. |
| 📱 **Interface responsiva** | Experiência adaptável a diferentes tamanhos de tela. |

## 🎯 Categorias e aplicações

As paletas podem atender a diferentes contextos de design e segmentos de mercado, como:

- **Corporativo e B2B:** ERPs, CRMs, sistemas internos e dashboards.
- **Tecnologia:** SaaS, ferramentas para desenvolvedores e produtos digitais.
- **Natural e sustentabilidade:** Agrotech, ESG e iniciativas ambientais.
- **Minimalista:** interfaces limpas, discretas e funcionais.
- **Luxo e sofisticação:** joalherias, marcas premium e produtos de alto padrão.
- **E-commerce e serviços:** lojas virtuais, delivery e plataformas comerciais.
- **Dark UI e alto contraste:** interfaces escuras e experiências que exigem contraste visual.

## 🚀 Como executar

O projeto é estático e não exige backend ou instalação de dependências de servidor.

### 1. Clone o repositório

```bash
git clone https://github.com/veniciussantossouza/color-palette-list.git
```

### 2. Entre na pasta

```bash
cd color-palette-list
```

### 3. Abra a aplicação

Abra o arquivo `index.html` diretamente no navegador.

Você também pode acessar a versão publicada:

**[Abrir Color Palette List](https://veniciussantossouza.github.io/color-palette-list/)**
